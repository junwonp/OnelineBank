# AGENTS.md

## Stack

- Expo ~58 · React Native 0.88 · React 19.3 · TypeScript ~6.0; pnpm 12.16.1 (`pnpm-lock.yaml`)
- Expo Router ~58 (file-based); NativeWind 5 RC on Tailwind 4 (`global.css`); typed routes + React Compiler on
- TanStack Query v5 (+persist), TanStack Form v1, Zustand v5, Zod v4
- Firebase v27: `@react-native-firebase/{app,auth,crashlytics,firestore}`; MMKV; Reanimated 4 + worklets

## Layout

- `app/` routes; `components/`, `features/`, `hooks/`, `lib/`, `utils/`; `assets/`, `scripts/`
- Root configs: `app.config.ts`, `babel.config.js`, `metro.config.ts`, `eslint.config.js`, `tsconfig.json`
- `ios/`, `android/`, `googleServices/` gitignored, generated by prebuild/EAS

## Commands

`pnpm run <script>`: `start`, `ios`, `android`, `web`, `lint`, `doctor`, `prebuild`, `pod-install`

## Conventions

- ESLint flat config: `eslint-config-expo`, `simple-import-sort`, `unused-imports` (error), TanStack Query + React Compiler plugins; imports sorted packages → `@/` → relative
- Prettier via ESLint (`endOfLine: auto`); Babel `babel-preset-expo` + `react-native-worklets/plugin`; Metro minifies with esbuild and drops `console`; `no-console` warn
